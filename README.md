# Retail Sales Analysis Dashboard

## Overview

This project analyzes retail sales data using **SQL Server and Power BI** to identify trends in sales, profitability, product performance, discounts, and regional performance.

The project demonstrates how raw business data can be analyzed with SQL and transformed into an interactive Power BI dashboard for business decision-making.

## Project Goals

* Analyze overall sales and profitability
* Identify high-performing products and sub-categories
* Evaluate the relationship between discounts and profit
* Compare regional sales and profitability
* Calculate and analyze profit margins
* Build an interactive business intelligence dashboard

## Tools & Technologies

* **SQL Server** — data analysis and business queries
* **Power BI** — interactive dashboard and data visualization
* **DAX** — calculated measures and KPIs
* **GitHub** — project documentation and version control

## SQL Analysis

The SQL analysis examines:

* Overall sales and profit
* Category and sub-category performance
* Discount levels and profitability
* Regional performance
* Profit margins
* Top 10 products by profit
* Sub-category profit rankings using the `RANK()` window function

## Power BI Dashboard

The Power BI dashboard provides an interactive view of retail performance, including:

* Sales and profit KPIs
* Regional performance
* Product performance
* Category and sub-category analysis
* Sales trends
* Interactive filtering

[View the Power BI Project](powerbi/)

## Key Business Insights

* Strong sales do not always translate into strong profitability.
* Higher discount levels are associated with lower profitability.
* Regional performance varies across the business.
* Product and sub-category performance varies significantly.
